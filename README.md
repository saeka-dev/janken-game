# はじめに
・本リポジトリはJava初学者がJava Swingを使用して初めて作成したじゃんけんゲームです。

# コンセプト
・ITパスポート試験の合格をきっかけに実際に何か作ってみたいと思い、初心者でも簡単に作れるログイン画面とじゃんけんゲームを作成しました。
・完成させることを目標に、機能を絞って実装しました。
# ゲーム概要
・本ゲームではログイン(IDとPassを入力)をしてCPUとじゃんけんをするゲームです。
・ボタンを押すことで自分の手を選んで勝負することができます。

# ログインについて
・本アプリはログイン機能の練習として作成したデモ用アプリです
・以下のIDとパスワードを入力するとログインできます
ーID : test
ーPass : 1234 (ログイン画面の表記に合わせています)
※実際の認証処理は行っておらず、学習目的の実装です

# 利用方法
・本アプリケーションはJavaおよびEclipseがインストールされた環境での実行を想定しています。
1. 本リポジトリをクローンまたはダウンロードします
2. Eclipseで既存のプロジェクトとしてインポートします
3. mainメソッドを実行します
4. アプリケーションが起動します
